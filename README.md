## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/nagendrakushwaha/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Run production build & verify types
npm run build
```

## 🌐 Deploying to Vercel

The application is pre-configured for seamless zero-configuration Vercel deployment:

1. Push this repository to GitHub.
2. In the **Vercel Dashboard**, click **Add New Project** and import the repository.
3. Build Settings are automatically detected:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Deploy! `vercel.json` ensures all SPA routes correctly rewrite to `/index.html`.
